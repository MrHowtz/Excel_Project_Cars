### Project Summary

The goal of this project was to conduct a deep dive into customer demographics and purchasing behavior. Using a refined consumer dataset, I’ve transformed raw numbers into a strategic roadmap for targeted marketing.

* **Data Preparation:** Cleaned, structured, and transformed raw data using advanced Excel formulas.
* **Visualization:** Developed interactive dashboards with synchronized Pivot Tables and Slicers.
* **Key Results:** Generated actionable insights focused on how occupation, education, and gender drive car purchase conversions across German states.

---

### Project Overview

This dashboard identifies the "why" behind the buy. By correlating socioeconomic variables, the project pinpoints the primary drivers of purchase decisions:

> **Core Variables Analyzed:** Income, Age, Education, Commute Distance, Occupation, and Gender.
